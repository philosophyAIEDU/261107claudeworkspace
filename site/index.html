폴더와 대화를 기억해요

어느 폴더에서 어떤 대화를 했는지 목록으로 남아요. 폴더 카드에 마지막 작업 시각, 대화 수, 최근 대화 제목이 보여요.

▶

누르면 바로 이어서

대화를 누르면 지난 이야기를 말풍선으로 보여 주고, 버튼 하나로 그 대화를 그 폴더에서 그대로 이어 가요.

⌨️

한글이 깨지지 않아요

터미널 아래 한글 입력창에 쓰고 [보내기]만 누르면 돼요. 여러 줄도 한 번에, 자주 쓰는 문장은 버튼으로.

🗂️

IDE처럼 파일도 함께

파일 탐색기와 편집기가 들어 있어요. Claude가 방금 고친 파일에는 ● 방금 바뀜 표시가 붙어요.

📥

예전 작업도 불러와요

다른 IDE 터미널에서 Claude Code로 작업했던 폴더와 대화도 찾아서 목록에 넣어 줘요.

🔒

내 컴퓨터 안에서만

API 키를 받지 않고, 대화 내용을 밖으로 보내지 않아요. 분석·추적 기능도 없어요. 로그인은 Claude Code가 직접 해요.

내려받기

내 컴퓨터에 맞는 파일을 골라요.

🪟 Windows 10/11 설치 파일 (.exe) 🍎 macOS · 애플 실리콘 M1·M2·M3·M4 맥 (.dmg) 🍏 macOS · 인텔 2020년 이전 맥 (.dmg)

맥 종류는 화면 왼쪽 위 사과 메뉴 → 이 Mac에 관하여의 “칩” 또는 “프로세서”에서 확인해요. 모든 버전은 GitHub 릴리스 페이지에 있어요.

⚠️ 처음 실행할 때 경고 창이 떠요 (괜찮아요)

아직 코드 서명이 되어 있지 않아서 운영체제가 확인 창을 보여 줘요. 아래처럼 실행하면 돼요.

Windows — “Windows의 PC 보호”

  1. 파란 창 안의 [추가 정보]를 눌러요.
  2. 아래에 생긴 [실행]을 눌러요.
  3. 설치 마법사에서 [설치]를 눌러요.

macOS — “열 수 없음”

  1. dmg를 열고 앱을 응용 프로그램 폴더로 끌어 놓아요.
  2. 앱을 Control 키를 누른 채 클릭하고 [열기]를 골라요.
  3. 그래도 안 되면 시스템 설정 → 개인정보 보호 및 보안에서 [그래도 열기]를 눌러요.

처음 써 보기 4단계

  1. Claude Code 준비하기

    이 앱은 내 컴퓨터의 Claude Code를 편하게 쓰도록 돕는 도구예요. 가장 쉬운 방법은 앱을 먼저 설치하고, 첫 화면의 [🪄 자동으로 설치하기]를 누르는 거예요. PATH 오류 걱정 없이 설치돼요. 직접 설치하려면 아래 명령을 써요.

    Windows (PowerShell) irm https://claude.ai/install.ps1 | iex
    macOS (터미널) curl -fsSL https://claude.ai/install.sh | bash

    자세한 안내: Claude Code 공식 설치 문서

  2. 앱을 설치하고 폴더 열기

    처음 화면에서 [📁 폴더 열기]로 기존 폴더를 고르거나, [➕ 새 작업 폴더 만들기]로 이름만 써서 새로 만들어요.

  3. 새 대화로 작업하기

    오른쪽 클로드 패널의 [＋ 새 대화]를 누르고(처음이면 안내에 따라 로그인), 아래 한글 입력창에 할 일을 쓰고 [보내기]를 눌러요.

  4. 다음에는 이어서

    다음에 앱을 켜면 처음 화면의 폴더 카드에서 [▶ 이어서 작업하기]만 누르면 돼요.

자주 묻는 질문

돈이 드나요?

앱은 무료예요. Claude를 쓰는 요금은 지금 쓰고 있는 Claude 요금제(또는 API 사용량)를 그대로 써요. 이 앱이 따로 요금을 받거나 API 키를 묻지 않아요.

개발자가 아니어도 쓸 수 있나요?

네. 모든 메뉴와 안내가 쉬운 한국어로 되어 있고, 어려운 말 옆에는 (?) 설명이 붙어 있어요. 도움말에는 용어 사전과 자주 쓰는 Claude 명령어 설명도 있어요.

예전에 다른 IDE(안티그래비티, VS Code 등)에서 한 대화도 볼 수 있나요?

네. 처음 실행할 때 “예전 작업 불러오기”에서 Claude Code로 작업했던 폴더를 찾아 보여 줘요. 체크하고 추가하면 그 폴더의 대화가 모두 목록에 들어와요.

IDE 터미널에서 Claude Code를 설치하면 어떤 사람은 PATH 오류가 나요. 왜 그런가요?

공식 설치 명령은 claude를 내 폴더\.local\bin에 넣지만 PATH(명령을 찾는 폴더 목록)에는 추가하지 않아요. 그 폴더가 원래 PATH에 있던 컴퓨터는 바로 되고, 없던 컴퓨터는 “인식되지 않는 명령” 오류가 나요. PATH를 고쳐도 이미 켜져 있던 IDE의 터미널은 옛 PATH를 쓰기 때문에 IDE를 완전히 껐다 켜야 해요. 이 앱은 [🪄 자동으로 설치하기]로 설치하고 PATH와 상관없이 claude를 찾아요. 다른 프로그램에서도 쓰려면 [🔧 PATH에 등록하기]를 누르면 돼요.

폴더를 옮겼더니 이어서 하기가 안 돼요.

Claude Code의 대화 기록은 처음 대화를 시작한 폴더 위치에 묶여 있어요. 처음 화면의 폴더 카드에서 [📍 새 위치 지정]으로 옮긴 폴더를 골라 주세요.

대화 내용이 인터넷 어딘가에 저장되나요?

이 앱은 대화 내용을 어디에도 보내지 않아요. 대화는 Claude Code가 평소처럼 처리하고, 기록은 내 컴퓨터에 남아요. 이 앱은 그 기록의 목록(색인)만 내 컴퓨터에 저장해요.
